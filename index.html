原生 macOS 体验Built for your Mac

SwiftUI 三栏界面，将账户、邮件列表与正文放在同一窗口。一个通用安装包，同时支持 Apple Silicon 和 Intel。

A native SwiftUI three-column layout keeps accounts, messages and reading together. One universal download runs on Apple Silicon and Intel Macs.

完整邮件工作流Everyday mail, covered

支持 IMAP、POP3 和 SMTP，以及收发邮件、草稿、回复、转发、存档、垃圾邮件、星标和已读状态管理。

Connect through IMAP, POP3 and SMTP. Read and send mail, manage drafts, reply, forward, archive, mark junk, star messages and track read status.

多账户管理Multiple accounts, separate indexes

在同一应用中管理个人、学校和工作邮箱。每个账户使用独立的本地向量库，AI 检索限定在当前账户范围。

Manage personal, school and work mail in one app. Each account has its own local vector database, and AI retrieval stays within the current account.

本地邮件索引Index on your own Mac

使用 Apple NaturalLanguage NLEmbedding 在本机生成向量，索引邮件正文和可读取的附件文本，不为生成向量上传邮件内容。

Apple NaturalLanguage NLEmbedding creates vectors locally from mail bodies and readable attachment text. Mail content is not uploaded to generate embeddings.

带来源的 AI 问答AI answers with source messages

用自然语言查找已索引邮件中的信息。回答支持 Markdown 和可点击的邮件引用，也可生成回复草稿，由你检查并发送。

Ask questions about indexed mail. Answers include Markdown formatting and clickable message references. Generate reply drafts, then review and send them yourself.

正文与附件Rich messages and attachments

阅读 HTML 邮件和内嵌图片，处理多语言主题及附件文件名。附件支持系统文件图标、打开和另存为。

Read HTML messages and embedded images, with decoding for multilingual subjects and filenames. Open or save attachments using familiar system file icons.

隐私与 AI 使用范围Your data and optional AI

密码、OAuth token 和 API Key 保存在 macOS 钥匙串。本地索引不上传邮件内容；使用可选的 AI 问答或回复功能时，相关邮件文本会发送给你配置的模型服务商。普通收发邮件不需要 AI API Key。

Passwords, OAuth tokens and API keys are stored in macOS Keychain. Local indexing does not upload mail content. Optional AI answers and replies send relevant mail text to the model provider you configure. Regular mail works without an AI API key.
